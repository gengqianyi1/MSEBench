# Hard-v2审核意见复核

- 保持1000条目标、20+2调用和短库固定1000分母，解决题面/评分冲突。
- 保持property与candidate子分独立报告；CHGNet明确为局部代理，权重由25降至10。
- 新增`prediction_model_sha256`、预测不确定性和适用域，回应候选预测不可追溯问题。
- 私有抽样、校准锚点和连续阈值不向模型公开；必交字段、科学含义、资格条件仍公开，避免隐藏契约。
- scorer、schema和回归测试已同步；旧runs不继承，防止版本混用。
- 公共/私有包隔离、未信任生成器沙箱和多种子正式校准仍是发布门禁，不因hard-v2降低要求。
