# Task 04 Harbor execution

Run protected case 1 through the organizer sidecar. Read the public question and
schemas with the declared tools, perform the xTB calculations you judge necessary,
write the required files into the submission directory, and call `submit`.

The evaluated model is supplied by Harbor. Private references, tests, and scoring
code are not in the model workspace. Network access is disabled. Reaching a turn,
tool, or compute budget stops new work but does not erase otherwise valid evidence;
the grader awards scientific partial credit from the saved submission and jobs.
