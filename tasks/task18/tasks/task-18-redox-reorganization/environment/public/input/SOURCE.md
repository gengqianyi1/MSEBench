# Public input provenance

The three XYZ files are frozen neutral-molecule coordinates derived from public-domain PubChem records. Their exact bytes and the SHA-256 values in `candidate_manifest.csv` define the benchmark inputs. Detailed source-record identifiers and acquisition hashes are retained by the organizer for provenance review but are not needed to solve the task.

Anonymous labels prevent name-based shortcuts. Solving and scoring use the supplied coordinates and organizer-recorded xTB evidence; no chemical name, precomputed energy, ranking, or reference result is required.

The full benchmark package is used internally for MSEBench evaluation under its evaluation license. The MSEBench data manifest records the release terms for these public inputs.
