# Design rationale — QED v4

The task measures constrained molecular editing, not recognition of a single reusable edit. Five cases vary their descriptor and topology requirements; a public halogen-count constraint prevents the same aromatic halogen substitution from solving the suite.

The deterministic beam uses only participant-visible state and the participant budget. Scores remain continuous when a chemically valid candidate partially satisfies objectives, while feasibility and budget violations remain explicit gates. Macro aggregation prevents one easy case from dominating; the stability component rewards cross-case reliability without duplicating a scientific fact.

Private case content is physically absent from the participant package. Hash commitments prove organizer asset integrity without publishing answers.
